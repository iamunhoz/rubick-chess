# Keyboard Shortcuts

All keyboard shortcuts for Rubicks Chess. Powered by [Mousetrap](https://craig.is/killing/mice).

## Piece Selection

| Key | Action |
|-----|--------|
| `Tab` | Select next piece (cycles through all pieces on the board) |
| `Shift+Tab` | Select previous piece |
| `Escape` | Deselect current piece / cancel |

## Move Navigation

When a piece is selected and has legal moves:

| Key | Action |
|-----|--------|
| `Right Arrow` | Highlight next legal move target (orange glow) |
| `Left Arrow` | Highlight previous legal move target |
| `Enter` / `Space` | Confirm move to the highlighted target |

## Camera

### Snap Views

| Key | View |
|-----|------|
| `F` | Front face |
| `B` | Back face |
| `L` | Left face |
| `R` | Right face |
| `U` | Top (Up) face |
| `D` | Bottom (Down) face |
| `I` | Isometric (diagonal) |

### Zoom

| Key | Action |
|-----|--------|
| `+` / `=` | Zoom in |
| `-` | Zoom out |

## Abilities (Corner Pieces Only)

When a corner piece is selected, number keys trigger its special abilities. The available abilities depend on the piece type:

### Bishop / Queen (Face Turn)

| Key | Action |
|-----|--------|
| `1` | Face Turn CW (clockwise) |
| `2` | Face Turn CCW (counter-clockwise) |

### Rook / Queen (Layer Turn)

| Key | Action |
|-----|--------|
| `3` | Row Turn CW |
| `4` | Row Turn CCW |
| `5` | Column Turn CW |
| `6` | Column Turn CCW |

### Queen (All Abilities)

Queens on corners have all 6 abilities: keys `1`-`6`.

## Menu

| Key | Action |
|-----|--------|
| `H` | Toggle HUD menu visibility |
| `Backspace` | Reset game |

## Notes

- All shortcuts are disabled during rotation animations.
- Mouse/touch controls still work alongside keyboard shortcuts.
- Camera drag-rotation uses mouse (left-click drag or right-click drag). Scroll wheel zooms.
- The orange move target highlight (keyboard navigation) is distinct from the green legal-move highlights.
